# FitZone Premium - Kebayoran

Premium gym and fitness center landing page for FitZone Premium in Kebayoran, Jakarta Selatan.

## Features

- **Responsive Design**: Optimized for all devices
- **3 Membership Tiers**: Starter, Premium (most popular), and Elite packages
- **Class Schedule**: Display of daily fitness classes
- **Trainer Profiles**: Meet our certified trainers
- **World-Class Facilities**: Showcase of premium gym amenities
- **WebP Images**: Optimized images for fast loading

## Tech Stack

- Pure HTML5, CSS3, JavaScript
- CSS Grid & Flexbox layouts
- CSS Variables for theming
- Smooth scroll navigation
- WebP image format for optimization

## Live Demo

Site is deployed on port 8119.

## Structure

- `index.html` - Main landing page
- `gym-*.webp` - Optimized WebP images
- All assets self-contained in single directory

## Design Approach

- **Surface Type**: Decide/Learn (marketing landing page)
- **Color Palette**: Dark theme with orange primary (#FF6B35) and yellow accent
- **Typography**: System font stack for performance
- **Layout**: Hero section, membership cards, schedule grid, trainer profiles, facilities grid
- **No Generic Slop**: Custom composition avoiding AI design clichés

Built with claude-design skill following best practices.
